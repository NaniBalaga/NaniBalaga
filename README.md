## CONNECT SRMAP: all-in-one student platform for SRM University AP
🔗 [oursrmap.purlyedit.in](https://oursrmap.purlyedit.in) · Solo developer: design, backend, database, deployment

A verified, student-only platform that brings academics, communication and campus life into one place.

**Academics**
- Dashboard with CGPA, attendance summary and upcoming classes
- Interactive timetable (subject, faculty, room, credits per class)
- Marks analysis, CGPA calculator, study materials vault and previous-year papers

**Community and communication**
- Real-time 1:1 and group chat; chat unlocks automatically on mutual follow
- Community hub (discussions, lost & found, team finder), anonymous confessions with scheduled reveals
- Section-mate directory with free-slot matching for study groups
- Block/report moderation with fast report review

**Campus life**
- Daily mess menus, faculty ratings, clubs and events, roommate swap, health and emergency links

**Security and accounts**
- OTP email verification and register-number-based student verification
- Account lockout after repeated failed logins, expiring one-time emergency login tokens
- Login history, account deletion and data export

**Stack:** PHP, MySQL, JavaScript, AJAX, SMTP · Mobile app in progress (React Native)

## VITAP UPDATES: student smart portal for VIT-AP
🔗 [lovevitap.purlyedit.in](https://lovevitap.purlyedit.in) · Solo developer

An unofficial student portal for VIT-AP with verified accounts and 15+ tools.

- **Verified access:** registration restricted to official university email, with OTP verification
- **Academic tools:** CGPA calculator (relative grading) and attendance calculator with history
- **Community:** anonymous faculty ratings with leaderboard, Help Space forum, hostel ratings, peer chat, FunRoom
- **Astra AI:** an AI assistant for student queries
- **Productivity:** private file storage, image-to-PDF converter, daily task manager, smart notifications
- **Privacy by design:** CGPA data stays on the user's device, password hashes are salted, deleted accounts are purged within 48 hours

**Stack:** PHP, MySQL, JavaScript, SMTP, JSON
